# Лабораторная работа №3. Навигация в своём проекте

## 1. Название проекта

MyJob – Трекер поиска работы.

## 2. Список маршрутов

| Адрес | Страница | Назначение |
|---|---|---|
| `/` | Главная (`DashboardPage`) | Сводка по поиску работы и последние отклики (готовая страница из ЛР №2) |
| `/applications` | Все отклики (`ApplicationsPage`) | Список откликов; на этом этапе заголовок, описание и ссылка «Добавить отклик» |
| `/applications/new` | Создание отклика (`ApplicationCreatePage`) | Форма добавления отклика; на этом этапе заголовок, описание и ссылка к списку |
| `/applications/:id` | Подробности отклика (`ApplicationDetailsPage`) | Данные одного отклика; показывает идентификатор из адреса, ссылки «К списку откликов» и «Редактировать» |
| `/applications/:id/edit` | Редактирование отклика (`ApplicationEditPage`) | Форма изменения отклика; показывает идентификатор из адреса, ссылка «К отклику» |
| `/analytics` | Аналитика (`AnalyticsPage`) | Показатели поиска работы; на этом этапе заголовок и описание |
| `/calendar` | Календарь (`CalendarPage`) | Собеседования и напоминания; на этом этапе заголовок и описание |
| `/settings` | Настройки (`SettingsPage`) | Импорт, экспорт и очистка данных; на этом этапе заголовок и описание |
| `*` | Страница не найдена (`NotFoundPage`) | Сообщение о неизвестном адресе и ссылка на главную |

Адреса описаны константами в `src/app/paths.ts`, таблица маршрутов находится в `src/App.tsx`.

### Визуальная реализация страниц (без логики)

| Страница | Что показано |
|---|---|
| `/applications` | Поиск по компании и должности; фильтры по статусу и категории; сортировка (по дате отклика, компании, должности, зарплате) и порядок; кнопка «Сбросить фильтры»; шесть откликов со статусом, категорией, зарплатой и датой; действия «в избранное», «редактировать», «архивировать»; кнопка «Добавить отклик» |
| `/applications/:id` | Компания, должность и статус; ключевые данные (зарплата, категория, формат работы, тип занятости, даты, e-mail, ссылка на вакансию); описание; заметки; история смены статусов; связанные собеседования |
| `/applications/new` | Форма с группами «Вакансия», «Условия работы», «Описание и заметки»: 13 полей с подписями и отметкой обязательных |
| `/applications/:id/edit` | Та же форма, заполненная демонстрационными данными |
| `/settings` | Импорт JSON (выбор файла), экспорт (выбор коллекций), локальные данные, параметры приложения, очистка данных |

Ограничения этой версии:

- данные на пяти страницах статичные и демонстрационные, они хранятся в `src/pages/previewData.ts` и не зависят от адреса: на любой `:id` показывается один и тот же отклик;
- не работают поиск, фильтры, сортировка, избранное, архивирование, сохранение форм, импорт, экспорт и очистка данных: эти элементы только оформлены, их поведение появится в позже. Формы и кнопки не отправляют данные и не перезагружают страницу;
- работают переходы: из списка и карточек на отклик и в редактирование, «К списку откликов», «Редактировать», «К отклику», «Отмена».

## 3. Описание общего меню

Меню повторяется на всех страницах и состоит из пяти пунктов, которые заданы в одном месте (`src/app/navigation.ts`): «Главная», «Отклики», «Календарь», «Аналитика», «Настройки».

- **Настольная версия (от 900 px):** боковая панель `Sidebar` с названием приложения, заметной кнопкой «Добавить отклик», пунктами меню и переключателем темы.
- **Мобильная версия (до 900 px):** нижняя панель `MobileNav` с теми же пятью пунктами и иконками, а также верхняя строка `AppHeader` с названием, кнопкой «+» (добавить отклик) и переключателем темы.
- **Активный пункт:** пункты сделаны на `NavLink`, текущий раздел выделяется цветом и получает атрибут `aria-current="page"`. Пункт «Главная» использует свойство `end`, чтобы не быть активным на других страницах. Пункт «Отклики» остаётся активным на вложенных адресах `/applications/new`, `/applications/:id` и `/applications/:id/edit`.

## 4. Используемые возможности React Router

| Возможность | Где используется |
|---|---|
| `BrowserRouter` | `src/main.tsx` – оборачивает приложение |
| `Routes`, `Route` | `src/App.tsx` – таблица маршрутов, вложенный маршрут-макет и маршрут `*` |
| `Outlet` | `src/components/layout/AppLayout.tsx` – место, куда подставляется содержимое страницы |
| `NavLink` | `Sidebar.tsx`, `MobileNav.tsx` – пункты меню с активным состоянием |
| `Link` | `ButtonLink.tsx` (кнопки-ссылки), `AppHeader.tsx`, `ApplicationCard.tsx`, `DashboardPage.tsx` |
| `useParams` | `ApplicationDetailsPage.tsx`, `ApplicationEditPage.tsx` – чтение `:id` из адреса |
| `useLocation`, `useNavigationType` | `ScrollToTop.tsx` – прокрутка наверх при переходе на новую страницу |

## 5. Динамические маршруты и страница 404

- `/applications/:id` и `/applications/:id/edit` – динамические адреса. Идентификатор берётся из адреса через `useParams` и показывается на странице. Загрузка самой записи по идентификатору относится к следующим заданиям, поэтому на этом этапе для несуществующего идентификатора страница отображается так же.
- Для неизвестных адресов (например, `/abc` или `/applications/app-001/unknown`) срабатывает маршрут `*`: отображается страница «Страница не найдена» со ссылкой «Вернуться на главную». Меню при этом остаётся на месте.

## 6. Переходы между страницами

Помимо меню, переходы реализованы на самих страницах:

- главная: кнопка «Добавить отклик» → `/applications/new`, ссылка «Все отклики» → `/applications`, название компании в карточке → `/applications/:id`;
- «Все отклики»: «Добавить отклик» → `/applications/new`;
- «Новый отклик»: «К списку откликов» → `/applications`;
- «Подробности отклика»: «К списку откликов» → `/applications`, «Редактировать» → `/applications/:id/edit`;
- «Редактирование отклика»: «К отклику» → `/applications/:id`;
- «Страница не найдена»: «Вернуться на главную» → `/`.
