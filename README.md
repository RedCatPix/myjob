# MyJob – Трекер поиска работы

MyJob – персональное веб-приложение для учёта поиска работы. Оно помогает вести отклики на вакансии, отслеживать их статусы, планировать собеседования и анализировать результаты поиска.

## Документация

- [docs/project-spec.md](docs/project-spec.md) – спецификация проекта: пользователь, проблема, основная сущность и её поля, страницы с URL, пользовательские сценарии, ограничения первой версии.
- [docs/lab-02-report.md](docs/lab-02-report.md) – отчёт по заданию 2.
- [docs/lab-03-report.md](docs/lab-03-report.md) – отчёт по заданию 3.

## Технологии

- React 18
- TypeScript (строгий режим)
- Vite
- React Router DOM 6 (`BrowserRouter`, `Routes`, `Route`, `Link`, `NavLink`, `Outlet`)
- lucide-react (иконки)
- CSS Modules и CSS-переменные

Планируется добавить в следующих заданиях: Recharts, Zod, date-fns, Redux Toolkit.

## Установка и запуск


## Реализованный функционал

### Задание 1

- проект на Vite, React 18 и TypeScript (строгий режим);
- запуск `npm run dev` и сборка `npm run build`;
- документация: README.md и docs/project-spec.md.

### Задание 2

- главная страница: заголовок и описание приложения, сводка по поиску, карточки шести последних откликов;
- mock-сервер: функция `getDashboardData()` возвращает 12 откликов и 6 категорий через `Promise` с задержкой 1200 мс;
- состояния страницы: «Загрузка...» до получения данных, сообщение об ошибке с кнопкой «Повторить загрузку»;
- светлая и тёмная темы: переключатель, выбор сохраняется в `localStorage`, а без сохранённого выбора тема берётся из настроек системы;
- адаптивная вёрстка.

### Задание 3

- маршрутизация на React Router 6: восемь адресов и страница «Страница не найдена» для неизвестных адресов;
- общий макет `AppLayout` с `Outlet`: боковое меню на настольных экранах (от 900 px), нижняя панель навигации и верхняя строка на мобильных;
- меню на `NavLink` с выделением текущего раздела;
- динамические адреса `/applications/:id` и `/applications/:id/edit`: страницы показывают идентификатор из адреса (`useParams`);
- переходы на страницах: кнопки «Добавить отклик», ссылка «Все отклики» на главной, ссылка на отклик в карточке, «К списку откликов», «Редактировать», «К отклику», «Вернуться на главную»;
- при переходе на новую страницу окно прокручивается наверх, при «Назад» и «Вперёд» прокрутка не сбрасывается.

Страницы `/applications`, `/applications/:id`, `/applications/new`, `/applications/:id/edit` и `/settings` оформлены визуально по описанию страниц из проекта, **без логики**:

- `/applications`: поиск по компании и должности, фильтры по статусу и категории, выбор сортировки и порядка, список откликов (компания, должность, категория, статус, зарплатные ожидания, дата) с действиями «в избранное», «редактировать», «архивировать»;
- `/applications/:id`: компания, должность, статус, ключевые данные (зарплата, категория, формат работы, тип занятости, даты, контакты, ссылка на вакансию), описание, заметки, история смены статусов, связанные собеседования;
- `/applications/new` и `/applications/:id/edit`: одна общая форма отклика с подписями полей, пустая при создании и заполненная при редактировании;
- `/settings`: импорт и экспорт JSON, локальные данные, параметры приложения, очистка данных.

Данные на этих страницах демонстрационные и статичные, они лежат в одном файле `src/pages/previewData.ts` и не зависят от адреса (на любой `:id` показывается один и тот же демонстрационный отклик). Поиск, фильтры, сортировка, избранное, архивирование, сохранение форм, импорт, экспорт и очистка пока не работают: эти элементы только оформлены, а их поведение будет реализовано в следующих заданиях. Работают переходы: открыть отклик, редактировать, вернуться к списку, отменить.

Страницы `/`, `/analytics` и `/calendar` без изменений: аналитика и календарь пока показывают заголовок и описание назначения.
