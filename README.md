# MyJob – Трекер поиска работы

MyJob – персональное веб-приложение для учёта поиска работы. Оно помогает вести отклики на вакансии, отслеживать их статусы, планировать собеседования и анализировать результаты поиска.

## Документация

Подробное описание приложения (пользователь, проблема, основная сущность и её поля, страницы с URL, пользовательские сценарии, ограничения первой версии) находится в файле [docs/project-spec.md](docs/project-spec.md).

## Технологии

На текущем этапе:

- React 18
- TypeScript
- Vite

Планируется добавить в следующих заданиях: React Router DOM 6, Recharts, Zod, date-fns, lucide-react, Redux Toolkit.

## Установка и запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовая сборка появится в папке `dist`. Просмотреть её локально можно командой `npm run preview`.

## Команды

| Команда | Назначение |
|---|---|
| `npm run dev` | Запуск сервера разработки |
| `npm run build` | Проверка типов TypeScript и сборка |
| `npm run preview` | Локальный просмотр собранной версии |
| `npm run lint` | Проверка кода линтером oxlint |
